## 📌 Om denne repoen

Dette er en øvingsrepo hvor jeg lærte grunnleggende Git- og GitHub-arbeidsflyt: opprette en lokal mappe, koble den til et repo på GitHub, og pushe endringer.

## 🛠️ Hva jeg lærte

- Initialisere et lokalt Git-repo (`git init`)
- Committe endringer (`git add`, `git commit`)
- Koble lokal mappe til GitHub (`git remote`)
- Pushe kode til GitHub (`git push`)
- Feilsøke vanlige git-feil (feil remote-URL, manglende branch-navn)
